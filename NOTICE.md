# Source and assets

Diverse Biomes uses newly implemented sampling, model-loading hooks, collision geometry and construction-preservation code for this release. Earlier private builds used components associated with GiantPlants and VegetationProtection; their implementation files are excluded from this release source and binaries. Selected historical setting keys are retained to read existing configuration data.

BepInEx, Harmony and DSPModSave are required separately. Galactic Scale is optional. The core and optional Galactic Scale adapter are this project's own assemblies; no game, Unity, Galactic Scale, DSPModSave, BepInEx or other authors' assemblies are bundled.
